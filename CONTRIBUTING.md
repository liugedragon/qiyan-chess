# Contributing

[README](README.md) · [简体中文](CONTRIBUTING.zh-CN.md)

Report bugs and propose changes in [this repository's issues](https://github.com/liugedragon/qiyan-chess/issues). Include the application version, Windows version, steps to reproduce and the relevant error message. Use a small synthetic PGN when a game is needed; remove account information, local paths and private games from attachments.

## Development

Follow [the Windows build instructions](docs/BUILDING.md), then create a branch for the change. Run `pnpm test` and `pnpm lint`; build the portable application and check any desktop behavior you changed. Use `pnpm format` for formatting. If translation keys change, update the matching translations with the project's i18n commands.

A pull request should explain the problem, the resulting behavior and how it was checked. Add regression coverage for game-state, review or protocol changes. State any platform or interactive checks that were not performed.

Keep caches, binaries generated by builds, user databases, tokens and personal game files out of Git. Preserve upstream copyright and license notices. Contributions to the application source use GPL-3.0-only; do not change the separate licenses of bundled third-party components or model weights.

QiyanChess is maintained separately from [En Croissant](https://github.com/franciscoBSalgueiro/en-croissant). Changes intended for that project should follow its own contribution process.
